🥋 MAI — Martial Arts Learning Platform
MAI (Martial Arts Learning) es una plataforma web dedicada a la exploración, el aprendizaje y el descubrimiento de las artes marciales. 
Su propósito es ofrecer una experiencia digital intuitiva y organizada en la que los usuarios puedan conocer diferentes disciplinas, profundizar en sus fundamentos y descubrir nuevas formas de desarrollar sus conocimientos marciales.

🎯 Objetivo del proyecto
Desarrollar una plataforma educativa que facilite el acercamiento a las artes marciales mediante recursos digitales, una experiencia de navegación clara y funcionalidades que promuevan el aprendizaje progresivo.
MAI busca integrar la tecnología con la cultura marcial, fomentando la disciplina, la curiosidad, el conocimiento y la mejora continua.

🎨 Identidad visual
La interfaz de MAI se inspira en la estética de un dojo japonés contemporáneo, con un enfoque visual sobrio, moderno y funcional.

🛠️ Tecnologías utilizadas:
HTML5 -	Estructura y organización del contenido.
API REST - Desarrollo de API
JSON - formato utilizado para enviar y recibir datos.
CSS3 - Diseño visual, estilos, animaciones y adaptación de la interfaz.
JavaScript - Lógica de la aplicación, interactividad y funcionalidades dinámicas.
Vite - Servidor de desarrollo y herramientas de compilación del frontend.
Git y GitHub - Control de versiones y alojamiento del código fuente.

🚀 Instalación y ejecución local
Requisitos previos
•	Node.js.
•	npm, incluido con Node.js.
•	Git, para clonar el repositorio.
1. Clonar el repositorio
git clone https://github.com/juanejm/MartialArts-Learning-Platform-ES.git
2. Entrar en la carpeta del proyecto
cd MartialArts-Learning-Platform-ES
3. Instalar las dependencias
npm install
4. Iniciar el servidor de desarrollo
python server.py
Esto mostrará en la terminal la dirección local donde podrás abrir la aplicación en tu navegador, normalmente:
http://localhost:8080/

📂 Organización del proyecto
La estructura puede variar a medida que evoluciona el desarrollo. Entre los archivos principales del frontend se encuentran:
MartialArts-Learning-Platform-ES/
├── index.html
├── styles.css
├── app.js
├── martial-arts-data.js
├── discipline-engine.js
├── training-engine.js
├── package.json
├── package-lock.json
├── .gitignore
└── README.md
•	index.html: estructura principal de la interfaz.
•	styles.css: identidad visual, distribución y estilos de los componentes.
•	app.js: lógica de interacción y coordinación de funcionalidades.
•	martial-arts-data.js: datos utilizados para representar disciplinas marciales.
•	discipline-engine.js: lógica relacionada con las recomendaciones de disciplinas.
•	training-engine.js: funcionalidades relacionadas con la planificación del entrenamiento.
•	package.json: configuración del proyecto y scripts de desarrollo.

🗺️ Visión a futuro:
MAI aspira a evolucionar hacia un entorno digital de aprendizaje marcial más completo, con mayores recursos de investigación, herramientas de seguimiento, recomendaciones más precisas y experiencias educativas que conecten el conocimiento teórico con la práctica responsable.
La visión del proyecto es convertir el aprendizaje de las artes marciales en una experiencia accesible, estructurada y enriquecedora.
